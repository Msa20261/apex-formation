# Module 1.1 — Les Variables

## C'est quoi une variable ?

Une variable c'est une **boite** qui stocke une valeur.
Tu lui donnes un nom, et tu mets une valeur dedans.

```
nomMaison = "Villa Soleil"
    ↑               ↑
  le nom        la valeur
```

---

## Les 4 types essentiels

| Type | Ce que ça stocke | Apex | Python | Java |
|------|-----------------|------|--------|------|
| Texte | `"Villa Soleil"` | `String` | *(auto)* | `String` |
| Nombre entier | `3` | `Integer` | *(auto)* | `int` |
| Nombre décimal | `250000.50` | `Decimal` | *(auto)* | `double` |
| Vrai / Faux | `true` ou `false` | `Boolean` | *(auto)* | `boolean` |

> En Python, tu n'as pas besoin d'écrire le type — Python le détecte seul.
