## Rôle de Python dans ta formation

Python n'est pas utilisé dans Salesforce directement, mais il est utile pour :
- Automatiser des tâches sur ton PC
- Faire des scripts de migration de données
- Interagir avec l'API Salesforce depuis l'extérieur
- Apprendre la logique de programmation plus facilement
