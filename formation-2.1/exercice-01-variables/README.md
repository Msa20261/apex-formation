# Exercice 01 — Les Variables

## C'est quoi une variable ?

Une variable, c'est une **boite** qui stocke une valeur.
Tu donnes un nom à la boite, et tu mets une valeur dedans.

Exemple : `nomMaison = "Villa Soleil"`
→ La boite s'appelle `nomMaison` et elle contient `"Villa Soleil"`

---

## Les types de variables (les 4 essentiels)

| Type | Ce que ça stocke | Exemple |
|------|-----------------|---------|
| `String` | Du texte | `"Villa Soleil"` |
| `Integer` / `int` | Un nombre entier | `3` |
| `Decimal` / `double` | Un nombre avec virgule | `250000.50` |
| `Boolean` / `bool` | Vrai ou Faux | `true` / `false` |
